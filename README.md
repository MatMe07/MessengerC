Было разработано клиент-серверное приложение, где несколько клиентов могут обмениваться сообщениями через центральный сервер. Помимо передачи сообщений сервер может передавать файлы и обрабатывать их по запросу клиентов (в данном случае подсчитывать количество пробелов).
Сервер создаёт общедоступный почтовый ящик и слушает все входящие сообщения. При подключении каждому клиенту присваивается уникальный номер. Сервер может как отвечать одному конкретному клиенту, так и всем сразу. У сервера есть свой список команд:
LIST – выводит список всех активных клиентов
ALL:<текст> – отправляет сообщение всем активным клиентам
ID:<текст> – отправляет сообщение клиенту по его ID
Все сообщения, переданные через сервер, а также команды, системные оповещения сохраняются в отдельном .txt файле – common_chat_history.

Клиент создаёт свой персональный почтовый ящик, заходит на сервер и запускает фоновый поток для асинхронного приёма ответов от сервера.
Подключение клиента к серверу:
1.	Нужно ввести Host Name сервера (имя компьютера, на котором располагается сервер).
2.	Нужно ввести Host Name клиента (имя компьютера, на котором располагается клиент, т.е. с которого совершается попытка подключения к серверу).
Клиенту доступны следующие команды:
<текст> - позволяет отправлять текстовые сообщения серверу
BROADCAST:<текст> - рассылка сообщения всем клиентам, находящимся в сети
TASK:<имя_файла> - запрос на подсчёт пробелов в конкретном файле формата .txt
SEND:<имя_файла> - позволяет отправлять файлы на сервер
GET:<имя_файла> - позволяет получать (скачивать) файлы с сервера
HISTORY – позволяет просмотреть лог всей переписки
exit – выход из системы
Все сообщения, отправленные клиентом, хранятся локально в истории.
